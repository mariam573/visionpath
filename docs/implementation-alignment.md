## Current app claims

- **Demonstrated in source, not hardware-validated:** camera preview controls, local status speech, native frame/resizer/TFLite integration points, stale-result rejection, tracking/cooldowns, and pause/background handling.
- **Not demonstrated as integrated inference:** object recognition. `mobile/src/vision/modelAsset.ts` is intentionally unbundled and the active screen must say preview/status-only while it is null.
- **Not implemented:** persistence, voice recognition/commands, find/read/ask modes, cloud questions, sharing, OCR, metric depth, or routing.
- **Not validated:** exact EAS project/build, named phones, TalkBack/RTL/large-text behavior, TTS voice availability, audio-route recovery, low-light/obstruction handling, thermal behavior, model accuracy, latency, battery, or offline inference.

Update this register with dated evidence paths and the responsible owner when a gate is completed. Never change a status to complete based on documentation or code presence alone.
